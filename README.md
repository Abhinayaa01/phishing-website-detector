# Phishing Website Detection Using Machine Learning

## Project Description

This project aims to detect phishing websites using machine learning techniques. Phishing websites attempt to deceive users into sharing sensitive information, such as passwords and banking details.

The project involves preprocessing website-related data, training a machine learning model, and testing website URLs to classify them as phishing or legitimate.

## Objectives

- Preprocess and prepare data for machine learning.
- Train a model to identify phishing and legitimate websites.
- Evaluate the model's performance.
- Test the model using sample website URLs.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn

## Project Files

- `Preprocessing_file.ipynb` — Data preprocessing.
- `ModelTraining_file.ipynb` — Model training and evaluation.
- `test_data.csv` — Sample data used for testing.

## Disclaimer

This project is intended for educational purposes. Predictions are not a guarantee that a website is safe or malicious.
